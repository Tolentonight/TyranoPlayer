## 💡 To Developers / 致开发者

I am primarily a visual novel player rather than an experienced iOS developer. I built this player out of sheer necessity because no suitable iOS runtime existed for TyranoScript games.

- The current implementation is a working proof-of-concept. The codebase might be rough or unoptimized.
- **Contributions are highly welcome!** Whether it's refactoring, fixing WebKit/audio bugs, improving the UI, or even building a 100x better native player inspired by this project—feel free to open a PR or fork it!

我本质上只是一个想在手机上玩视觉小说的普通玩家，并不是专业的 iOS 开发者。因为在社区里实在找不到能用的 iOS 端 Tyrano 播放器，才自己硬着头皮摸索做出了这个可用版本。

- 目前的代码只是一个跑通了核心功能的“毛坯房”，可能存在很多不规范或需要优化的地方。
- **非常欢迎各位技术大佬提交 PR、重构代码或提出建议！** 如果这个项目能作为一块“垫脚石”，启发有能力的朋友去做出一个体验好百倍的成熟方案，那就再好不过了
